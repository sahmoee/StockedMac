# StockedMac Support

Email [support@sowensstudios.com](mailto:support@sowensstudios.com) with the StockedMac version/build, macOS version, source type, and sanitized activity output. Remove household codes, Worker credentials, private recipe URLs, and personal dietary details before sending.

Before writing, run the parser self-test, confirm Worker configuration in Settings, try a direct recipe URL, and check whether the site blocks automated requests. StockedMac respects source availability and cannot guarantee every publisher's markup remains compatible.
